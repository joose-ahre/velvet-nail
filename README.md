# Velvet Nails

Aplicación de reservas para un estudio de uñas, migrada a Next.js.

## Desarrollo

```bash
npm install
npm run dev
```

Abrí `http://localhost:3000` en el navegador.

Los datos de la demo se guardan localmente en el navegador. Para entrar como dueña:

- Email: `owner@velvetnails.com`
- Contraseña: `admin123`
